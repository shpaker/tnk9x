# Веб-сборка и мосты площадок

Один и тот же `tnk9x.wasm` работает на любой веб-площадке. Go знает только нейтральный мост `window.tnk9xPlatform` (`internal/adapters/platform`, `internal/repositories/raw/storage_web.go`). Всё, что относится к конкретному порталу, живёт в `web/<площадка>/` и в Go не попадает.

```
web/
  common/bridge.js    # базовый мост: поведение обычной страницы
  common/boot.js      # загрузчик: wasm + init() моста, затем go.run
  pages/index.html    # GitHub Pages: базовый мост, ссылка на репозиторий
  yandex/index.html   # Яндекс Игры: /sdk.js, без внешних ссылок
  yandex/platform.js  # мост Яндекс Игр поверх базового
```

Сборка: `just build-web <площадка>` кладёт в `dist/<площадка>/` wasm, `wasm_exec.js`, файлы `common/` и `<площадка>/`. Порядок скриптов на странице: `bridge.js` → `platform.js` портала (если есть) → `wasm_exec.js` → `boot.js`.

## Контракт `window.tnk9xPlatform`

Методы моста не бросают исключений: `syscall/js` превращает их в panic игры.

| Член | Кто вызывает | Смысл |
|---|---|---|
| `init(): Promise` | `boot.js` | Подготовка площадки до запуска игры (SDK, облачные сохранения); идёт параллельно с загрузкой wasm, `boot.js` ждёт её не дольше 5 с |
| `suspended: boolean` | игра, каждый кадр | Площадка приостановила игру: реклама, скрытая вкладка, пауза портала. Игра не обновляется, звук молчит |
| `suspensions: number` | игра, каждый кадр | Счётчик начатых приостановок: ловит приостановку, прошедшую целиком, пока кадры не шли (скрытая вкладка) — уровень уходит на паузу |
| `ready()` | игра | Загрузка позади, игрок может играть (появилось главное меню) |
| `gameplay(active)` | игра | Идёт ли активный геймплей; вызывается только при изменении |
| `intermission()` | игра | Логическая пауза между экранами: площадка может показать межуровневую рекламу и на это время поставить `suspended` |
| `rating()` | игра | Удачный момент попросить оценить игру (несколько побед за сессию, `rating_after_victories` в `config.yml`); спрашивать ли и как часто, решает площадка |
| `language: string` | игра, при запуске | Язык интерфейса площадки (`ru`, `ru-RU`); игра сводит его к поддерживаемому, `""` — неизвестен |
| `rewardAvailable: boolean` | игра | Площадка умеет рекламу за вознаграждение; без неё пункты REVIVE и BOOST не показываются |
| `requestReward()` | игра | Показать рекламу за награду по действию игрока |
| `rewardStatus(): string` | игра | `"pending"`, пока реклама идёт; итоговый `"granted"` или `"denied"` отдаётся один раз; иначе `""` |
| `purchasesAvailable: boolean` | игра | Площадка продаёт товары; без неё пункта SHOP нет |
| `catalog(): {id, price}[]` | игра | Товары площадки; `price` — строка с валютой, как её показывает площадка. В магазине — только товары `config.yml` с ID из каталога |
| `purchases(): {id, token}[]` | игра | Покупки игрока: разовые и ещё не списанные расходуемые; игра зачисляет их при запуске, при входе в главное меню и после оплаты |
| `requestPurchase(id)` | игра | Открыть окно оплаты товара по действию игрока; на это время площадка ставит `suspended` |
| `purchaseStatus(): string` | игра | `"pending"`, пока окно оплаты открыто; итоговый `"granted"` (покупка уже в `purchases()`) или `"denied"` отдаётся один раз; иначе `""` |
| `consumePurchase(token)` | игра | Списать расходуемую покупку: игра зачислила и сохранила товар |
| `storage.getItem(key): string \| null` | игра | Сохранения игры; `null` — ключа нет |
| `storage.setItem(key, value): boolean` | игра | Запись; `false` — хранилище отказало |
| `suspend(reason)`, `resume(reason)` | мосты порталов | Причины приостановки; игра стоит, пока есть хоть одна |
| `addSuspendListener(fn)` | мосты порталов | Подписка на смену `suspended` |
| `setLanguage(language)` | мосты порталов | Язык площадки, он же `lang` страницы; задаётся в `init()`, до запуска игры |

## Базовый мост (`common/bridge.js`)

- приостановка на скрытой вкладке (`visibilitychange`);
- звук: `AudioContext` игры приостанавливается вместе с игрой и возобновляется после неё (на iOS — с первым жестом);
- фокус клавиатуры на канвасе, в том числе внутри iframe портала;
- сохранения в `localStorage`;
- язык — язык браузера (`navigator.language`);
- рекламы и покупок нет.

## Яндекс Игры (`yandex/`)

- язык — язык интерфейса Яндекс Игр (`environment.i18n.lang`), определяется в `init()` до запуска игры (требование 2.14);
- `YaGames.init()`, `LoadingAPI.ready()`, `GameplayAPI.start/stop` по фронтам «игра размечает геймплей и не приостановлена»;
- `game_api_pause`/`game_api_resume` — причина приостановки `portal`;
- `adv.showFullscreenAdv` и `adv.showRewardedVideo` — причина `ad`;
- оценка игры `feedback.canReview` → `requestReview` — не чаще раза за запуск и не поверх рекламы, окно оценки — причина приостановки `rating`;
- покупки `getPayments({ signed: false })`: каталог и покупки игрока загружаются в `init()`, окно оплаты `purchase` — причина приостановки `purchase`, расходуемые покупки списываются `consumePurchase` после зачисления в игре;
- облачные сохранения `player.getData/setData` (облако главнее, локальные сохранения переносятся в него и остаются запасной копией; облако, ответившее после старта игры, в этом запуске не используется);
- без внешних ссылок, контекстное меню и выделение отключены.

Сборка и проверка:

- `just package-yandex` — архив `_build/tnk9x_yandex_<версия>.zip` с `index.html` в корне, загружается в консоль разработчика вручную;
- `just serve-yandex` — локальный запуск через `@yandex-games/sdk-dev-proxy` (нужен Node.js): без `YANDEX_APP_ID` — dev-режим с моками SDK, с ним — черновик игры на Яндексе.

Товары заводятся в консоли разработчика вручную: ID — как в разделе `shop` файла `config.yml` (`no_ads`, `all_levels`, `pack_2`…`pack_7`, `tokens_5`, `tokens_15`, `tokens_40`), названия и описания на ru/en/tr — те же, что в описаниях магазина игры (`shop.desc_*` в `assets/locales/`): окно оплаты Яндекса показывает их игроку.

ID игры и любые ключи площадок в репозиторий не попадают: `YANDEX_APP_ID` берётся из окружения или локального `.env` (он в `.gitignore`).

## Новая площадка

1. `web/<площадка>/index.html` — страница по образцу `yandex/index.html`.
2. `web/<площадка>/platform.js` — переопределяет нужные члены моста поверх базового.
3. Go не меняется; `just build-web <площадка>`.
