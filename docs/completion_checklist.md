# Чеклист завершения игры Gonflict (Battle City)

## 🎯 Критичные элементы (обязательно для завершения)

### 1. База и защита
- [x] Добавить базу (орёл) на карту (фиксированная позиция снизу) ✅ Реализовано через `config.yml` (`hq_position`)
- [x] База может быть разрушена пулями врагов ✅ Реализовано через `HQUseCases.HandleBulletHit()`
- [ ] Проигрыш при уничтожении базы (требуется интеграция Game Over)
- [x] Визуализация базы (статический спрайт) ✅ Реализовано (`hq_intact`, `hq_destroyed` спрайты)
- [x] Анимация взрыва базы ✅ Реализовано через `HQUseCases` и `HQStateExploding`

## 📝 Примечания

**Минимальный MVP для завершения:**
1. База + защита базы ✅
2. Система жизней + Game Over
3. Система очков
4. Бонусы (минимум 2-3 типа)
5. Главное меню + экраны победы/поражения
6. HUD с основными показателями
7. Переход между уровнями ✅ (реализован экран выбора уровня)

**Реализованные архитектурные улучшения:**
- ✅ Система состояний игры (GameState, StageSelectState)
- ✅ Переходы между состояниями через SessionEntity
- ✅ Репозиторий для работы со шрифтами (FontsRepository)
- ✅ Централизованная обработка ESC в App
- ✅ Работа с ресурсами через репозитории (запрет прямого обращения к файловой системе)
- ✅ Реорганизация системы коллизий:
  - Сервисы коллизий вынесены в `internal/services/collision_services`
  - Разделение ответственности: сервисы проверяют, use cases манипулируют данными
  - Универсальный интерфейс `IEntityCollider` для всех сущностей
  - Unit-тесты для сервисов коллизий

**Приоритет:** Реализовать критичные элементы → затем полировка.
