# Чеклист завершения игры Gonflict (Battle City)

## 🎯 Критичные элементы (обязательно для завершения)

### 1. База и защита
- [ ] Добавить базу (орёл) на карту (фиксированная позиция снизу)
- [ ] База может быть разрушена пулями врагов
- [ ] Проигрыш при уничтожении базы
- [ ] Визуализация базы (статический спрайт)

### 2. Система жизней и смерти
- [ ] Система жизней игрока (3 жизни по умолчанию)
- [ ] Респавн игрока после смерти (с анимацией)
- [ ] Game Over при потере всех жизней
- [ ] Показ количества жизней в HUD

### 3. Система очков и уничтожения врагов
- [ ] Начисление очков за уничтожение врагов
- [ ] Разные очки за разные типы врагов
- [ ] Отображение очков в HUD
- [ ] Подсчёт уничтоженных врагов

### 4. Бонусы и power-ups
- [ ] Спавн бонусов при уничтожении врагов (случайно)
- [ ] Типы бонусов:
  - [ ] Звезда (увеличение скорости пуль)
  - [ ] Танк (дополнительная жизнь)
  - [ ] Шлем (временная неуязвимость)
  - [ ] Лопата (укрепление базы)
  - [ ] Граната (уничтожение всех врагов)
- [ ] Подбор бонусов танком
- [ ] Визуализация бонусов (анимация)

### 5. UI и меню
- [ ] Главное меню:
  - [ ] Заголовок игры
  - [ ] Кнопка "Новая игра"
  - [ ] Кнопка "Выход"
- [ ] Экран выбора уровня (35 уровней)
- [ ] HUD во время игры:
  - [ ] Очки
  - [ ] Жизни
  - [ ] Номер уровня
  - [ ] Врагов осталось
- [ ] Экран Game Over:
  - [ ] Показ финальных очков
  - [ ] Кнопка "Попробовать снова"
  - [ ] Кнопка "В главное меню"
- [ ] Экран победы (уровень пройден):
  - [ ] Статистика уровня
  - [ ] Кнопка "Следующий уровень"
- [ ] Пауза (ESC):
  - [ ] Заморозка игры
  - [ ] Меню: "Продолжить", "Выйти в меню"

### 6. Игровая механика
- [ ] Система волн врагов:
  - [ ] Спавн врагов волнами (4-5 волн за уровень)
  - [ ] Фиксированное количество врагов на уровень
  - [ ] Следующая волна после уничтожения текущей
- [ ] Разные типы врагов:
  - [ ] Обычный (базовый)
  - [ ] Быстрый (высокая скорость)
  - [ ] Бронированный (требует больше попаданий)
  - [ ] Босс (на определённых уровнях)
- [ ] Переход между уровнями:
  - [ ] Автоматический переход на следующий уровень
  - [ ] Увеличение сложности
  - [ ] Сохранение прогресса

## 📝 Примечания

**Минимальный MVP для завершения:**
1. База + защита базы
2. Система жизней + Game Over
3. Система очков
4. Бонусы (минимум 2-3 типа)
5. Главное меню + экраны победы/поражения
6. HUD с основными показателями
7. Переход между уровнями

**Приоритет:** Реализовать критичные элементы → затем полировка.
