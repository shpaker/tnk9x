# Чеклист завершения Gonflict

Документ помогает отслеживать прогресс к версии 1.0. Отметьте пункт, когда функциональность реализована и покрыта тестами/документацией.

## Критичный минимум (MVP)

- [x] База (орёл) на карте, уязвимая для врагов (`HQUseCases`)
- [ ] Game Over при разрушении базы и переход к экрану поражения
- [ ] Система жизней игрока (3 жизни, респавн, Game Over)
- [ ] HUD с очками, жизнями, номером уровня
- [ ] Базовая система очков и подсчета уничтоженных врагов
- [ ] Бонусы (минимум 2 типа) с отображением и обработкой
- [ ] Главное меню и переход в игру через `StateTransitionUseCases`

## Игровая механика

- [x] Экран выбора уровня (`StageSelectState`, `StageSelectorUseCases`)
- [x] Пошаговое управление танком с торможением (`TankBrakingService`)
- [x] Коллизии пуль, блоков, танков (`CollisionUseCases` + сервисы)
- [ ] Волны врагов и ограничение количества на уровне
- [ ] Разные типы врагов (скорость, броня, поведение)
- [ ] Улучшения танка игрока (пули, скорость, броня)
- [ ] Система прогрессии между уровнями (переходы, сохранение состояния)

## Напоминания

- Любая новая функциональность должна проходить через интерфейсы, определенные в `internal/interfaces/*`.
- Перед закрытием пункта выполните `just check`.
- Обновляйте README и документацию, если меняется пользовательский опыт.
