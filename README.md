# Gonflict

Минимальный, но расширяемый Go проект для обучения - консольное приложение.

## Структура проекта

```
gonflict/
├── cmd/                    # Точки входа приложения
│   └── main.go            # Главный файл приложения
├── internal/              # Внутренние пакеты (не импортируются извне)
│   ├── app/               # Основная логика приложения
│   ├── config/            # Конфигурация
│   ├── service/           # Бизнес-логика
│   └── utils/             # Внутренние утилиты
├── version/               # Информация о версии
├── go.mod                 # Модуль Go
├── justfile              # Команды для сборки и разработки
└── README.md             # Документация
```

## Быстрый старт

### Требования

- Go 1.24.3 или выше
- Just (современная альтернатива Make) - [установка](https://github.com/casey/just#installation)

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd gonflict
```

2. Установите зависимости:
```bash
just deps
```

3. Запустите приложение:
```bash
just run
```

Или для разработки:
```bash
just dev
```

## Доступные команды

- `just build` - собрать приложение
- `just run` - собрать и запустить
- `just dev` - запустить в режиме разработки
- `just test` - запустить тесты
- `just test-coverage` - запустить тесты с отчетом покрытия
- `just clean` - очистить собранные файлы
- `just fmt` - форматировать код
- `just lint` - запустить линтер
- `just check` - запустить все проверки (fmt, lint, test)
- `just ci` - полный CI pipeline
- `just help` - показать все доступные команды

## Функциональность

Приложение представляет собой простой Hello World с архитектурным разделением на слои:

- Запускается и выводит информацию о версии
- Выполняет основную логику в сервисном слое (печатает "Hello, World!")
- Корректно завершается после выполнения

### Пример вывода

```

Running application...
Hello, World!
2024/01/15 10:30:00 Starting application: v1.0.0
2024/01/15 10:30:00 Service layer: Hello, World!
2024/01/15 10:30:00 Application completed successfully
2024/01/15 10:30:00 Application stopped gracefully
```

## Конфигурация

Приложение можно настроить через переменные окружения:

```bash
export APP_NAME=gonflict
export LOG_LEVEL=info
```

Или создать файл `.env` на основе `.env.example`.

## Расширение проекта

Этот проект создан как минимальная основа для изучения архитектуры Go приложений:

1. **Бизнес-логика** - расширяйте метод `PrintHelloWorld()` в `internal/service/`
2. **База данных** - создайте `internal/repository/` для работы с данными
3. **Валидация** - добавьте `internal/validator/` для проверки входных данных
4. **Обработка ошибок** - создайте `internal/errors/` для централизованной обработки ошибок
5. **Тесты** - создавайте тесты в соответствующих `*_test.go` файлах

## Архитектура

Проект следует принципам Clean Architecture:

- **cmd/** - точка входа приложения
- **internal/app/** - координация компонентов
- **internal/service/** - бизнес-логика
- **internal/config/** - конфигурация
- **internal/utils/** - внутренние утилиты
